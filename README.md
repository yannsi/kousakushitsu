# yannsiの工作室

夜な夜な作ったものの置き場です。

ページを開くたびに GitHub の yannsi の公開リポジトリを読み込んで、作品を自動で並べます。

- 公開先: https://yannsi.github.io/kousakushitsu/
- 作品の日本語名は `index.html` の中の `NAMES`（なまえ帳）に書きます
- なまえ帳に載っていない作品は、リポジトリの About（説明）がカードに出ます
- GitHub Pages があるリポジトリは「ページで動く作品」、ないものは「道具・スクリプト」に並びます
- フォークしたリポジトリ、アーカイブしたリポジトリ、`yannsi.github.io`、`expo`（名刺QRの入口）、このリポジトリ自身は並びません
